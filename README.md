## 🌟 প্রজেক্ট পরিচিতি (Project Overview)

**RAJ Courier Presentation & System Simulator** হলো একটি আধুনিক, হালকা ও জিরো-বিল্ড (Zero-Build) ইন্টারেক্টিভ প্ল্যাটফর্ম। এর মাধ্যমে ক্লায়েন্ট, ইনভেস্টর এবং ম্যানেজমেন্টের কাছে রাজ কুরিয়ারের সম্পূর্ণ কারিগরি আর্কিটেকচার, ব্যবসায়িক মডেল এবং ৯টি অপারেশনাল লাইফসাইকেল জীবন্তভাবে তুলে ধরা হয়েছে।

কোনো প্রকার ব্যাকএন্ড সার্ভার বা ডাটাবেজ ইনস্টলেশন ছাড়াই এটি সরাসরি ব্রাউজার বা মোবাইলে তাৎক্ষণিকভাবে চলে।

## 🎯 মূল ফিচারসমূহ (Core Modules)

### ১. এক্সিকিউটিভ প্রেজেন্টেশন ও আর্কিটেকচার ডেক
- কুরিয়ার ইন্ডাস্ট্রির জটিল সমস্যা ও তার আধুনিক প্রযুক্তিগত সমাধান।
- ৪টি প্রধান প্ল্যাটফর্ম (মার্চেন্ট অ্যাপ, রাইডার অ্যাপ, ব্রাঞ্চ হাব পোর্টাল, সুপার অ্যাডমিন)।
- **The Unified TypeScript Stack:** Fastify + PostgreSQL + Prisma ORM + Redis BullMQ + React + React Native।
- ০% ল্যাগ (Zero-Lag) সার্ভার আর্কিটেকচার নীতি ও নিরাপত্তা ব্যবস্থা।

### ২. ইন্টারেক্টিভ টেকনিক্যাল ডিকশনারি (Glossary Cards)
- লজিস্টিকস ও সফটওয়্যারের জটিল কনসেপ্ট সহজ ভাষায় ব্যাখ্যাকৃত (PostGIS জিও-ফেন্সিং, বুলএমকিউ কিউ, আইডেমপোটেন্সি, থার্মাল বারকোড প্রিন্টিং, ডাবল-এন্ট্রি লেজার, ইত্যাদি)।
- ক্যাটাগরি অনুযায়ী ফিল্টারিং এবং সার্চ সুবিধা।

### ৩. ৯-ধাপের এন্ড-টু-এন্ড লাইভ অপারেশনাল সিমুলেটর (Live Simulator)
- **৪টি সমান্তরাল ডিভাইস স্ক্রিন:**
  1. **মার্চেন্ট স্মার্টফোন (RAJ Merchant App):** পার্সেল এন্ট্রি, ট্র্যাকিং ও বিকাশ ওয়ালেট।
  2. **রাইডার স্মার্টফোন (RAJ Rider Pro App):** রাইডার টাস্ক, ক্যামেরা স্ক্যানার ও মিরপুর রানশিট।
  3. **ডেস্কটপ ওয়েব পোর্টাল (Hub Portal):** হাব ইনচার্জ ড্যাশবোর্ড, বারকোড স্ক্যান গান ও ব্যাংক ভাউচার।
  4. **পাবলিক ট্র্যাকিং ও এসএমএস (Customer View):** লাইভ টাইমলাইন, ওটিপি কার্ড ও ড্রাইভার কল।
- **বাস্তবসম্মত সাউন্ড সিন্থেসাইজার:** Web Audio API চালিত বারকোড গান লেজার বিপ (`1400Hz`), সাকসেস পেমেন্ট চাইম এবং ইন্টারফেস সাউন্ড।

### ৪. ফুল মার্চেন্ট অ্যাপ মোড (🏪 RAJ Merchant)
- হোম, পার্সেল বুকিং লিস্ট, বিকাশ ওয়ালেট ট্রানজেকশন লেজার ও শপ প্রোফাইল।

### ৫. ফুল রাইডার অ্যাপ মোড (🛵 RAJ Rider Pro)
- ডেলিভারি টাস্ক লিস্ট, বারকোড ক্যামেরা স্ক্যানার, মিরপুর রানশিট রুট ম্যাপ এবং ক্যাশ আর্নিং/ভল্ট।

### ৬. ব্রাঞ্চ ও হাব অপারেশনাল ড্যাশবোর্ড (🏢 Branch Dashboard)
- ব্রাঞ্চ কোড `SYL-01` (সিলেট সেন্ট্রাল হাব)।
- লাইভ ইনবাউন্ড (৩৮০টি), আউটবাউন্ড (৩২০টি), সক্রিয় রাইডার (১৬ জন) ও ক্যাশিয়ার ভল্ট (৳২,৮৫,৪০০)।
- হাইওয়ে ট্রাক আনলোড বারকোড গান স্ক্যানিং ও রাইডার রানশিট ডিসপ্যাচ।
- ক্যাশিয়ার ভল্ট থেকে সেন্ট্রাল ব্যাংকে ডিপোজিট চালান তৈরির ইন্টারেক্টিভ সিমুলেশন।

### ৭. সেন্ট্রাল ওনার ম্যানেজমেন্ট ড্যাশবোর্ড (👑 Owner Central BI)
- ৬৪ জেলার ব্রাঞ্চ ভল্ট ক্যাশ ও সেন্ট্রাল ব্যাংক ব্যালেন্স রিয়েল-টাইম প্রদর্শন।
- প্রতিটি ব্রাঞ্চের দ্বি-মুখী পার্সেল মনিটরিং (ইনবাউন্ড আসবে vs আউটবাউন্ড যাবে)।
- হাইওয়ে লাইনহল ট্রাক লাইভ ট্র্যাকিং ও অটোমেটেড ফ্রড ডিটেকশন অ্যালার্ট।

## 🛠️ প্রযুক্তিগত বৈশিষ্ট্য (Tech Architecture)

- **স্ট্রিক্ট কোড কোয়ালিটি রুল:** রিপোজিটরির প্রতিটি সোর্স ফাইল কঠোরভাবে ১০০০ লাইনের নিচে (সবগুলো ৭৫০ লাইনের নিচে) মডুলার ফাইলে বিভক্ত।
- **পাসওয়ার্ড সিকিউরিটি গেট:** ক্লায়েন্ট ডেমোর সুরক্ষার জন্য `RAJ2026` অথেনটিকেশন গেট।
