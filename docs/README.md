# 📚 রাজ কুরিয়ার সিস্টেম মাস্টার ডকুমেন্টেশন ইনডেক্স (Project Specification Index)

এই ডিরেক্টরিতে রাজ কুরিয়ার (RAJ Courier) লজিস্টিকস প্ল্যাটফর্মের সম্পূর্ণ কারিগরি পরিকল্পনা, আর্কিটেকচার ব্লুপ্রিন্ট, ডাটাবেজ মডেল এবং সিমুলেশন লাইফসাইকেলের বিস্তারিত ডকুমেন্টেশন সাজানো রয়েছে:

---

## 📑 ডকুমেন্টেশন সূচিপত্র:

1. **[01. ফুল-স্ট্যাক মাস্টার স্পেসিফিকেশন (01_COURIER_MASTER_SPECIFICATION.md)](./01_COURIER_MASTER_SPECIFICATION.md)**
   - পূর্ণাঙ্গ সিস্টেম আর্কিটেকচার, ডোমেইন লজিক ও রোলস (RBAC)।
   - ক্যানোনিকাল টেক-স্ট্যাক (Fastify + TypeScript + PostgreSQL + Prisma + Redis BullMQ + React + React Native)।
   - সম্পূর্ণ Prisma ডাটাবেজ স্কিমা (ইউজার, পার্সেল, চালন, লেজার, ব্রাঞ্চ ও অডিট লগ)।
   - RESTful API রুট তালিকা এবং সিকিউরিটি পলিসি।

2. **[02. টেক ব্লুপ্রিন্ট ও জিরো-ল্যাগ আর্কিটেকচার (02_COURIER_SYSTEM_ARCHITECTURE.md)](./02_COURIER_SYSTEM_ARCHITECTURE.md)**
   - ৪টি মূল অ্যাপ ও প্ল্যাটফর্মের দায়িত্ব বণ্টন (রাইডার অ্যাপ, হাব ম্যানেজার, মার্চেন্ট পোর্টাল, সুপার অ্যাডমিন)।
   - ডাটাবেজ মাস্টার-রেপ্লিকা এবং Redis Cache-Aside প্যাটার্ন।
   - জিরো-ল্যাগ (Zero-Lag) সার্ভার স্কেলিং ও Nginx/Cloudflare কনফিগারেশন।

3. **[03. ওনার সেন্ট্রাল ড্যাশবোর্ড স্পেসিফিকেশন (03_OWNER_CENTRAL_DASHBOARD_SPEC.md)](./03_OWNER_CENTRAL_DASHBOARD_SPEC.md)**
   - ৬৪ জেলার ব্রাঞ্চ ভল্ট ক্যাশ, সেন্ট্রাল ব্যাংক ব্যালেন্স ও ক্যাশ-ইন-ট্রানজিট অডিট।
   - প্রতিটি ব্রাঞ্চের দ্বি-মুখী পার্সেল ফ্লো (ইনবাউন্ড আসবে vs আউটবাউন্ড যাবে)।
   - হাইওয়ে ট্রাক ও লাইনহল লাইভ ট্র্যাকিং লজিক।
   - অটোমেটিক ফ্রড ডিটেকশন ও অ্যালার্ট পলিসি।

4. **[04. এন্ড-টু-এন্ড সিমুলেটর ও লাইফসাইকেল গাইডলাইন (04_SIMULATOR_LIFECYCLE_GUIDE.md)](./04_SIMULATOR_LIFECYCLE_GUIDE.md)**
   - সিমুলেটরের ৯টি অপারেশনাল ধাপ (বুকিং থেকে শুরু করে রাইডার পিকআপ, হাব সর্টিং, হাইওয়ে ট্রাক, ওটিপি ডেলিভারি ও ওয়ালেট পেআউট)।
   - ৪টি আলাদা ডিভাইস স্ক্রিনের আর্কিটেকচার (মার্চেন্ট ফোন, রাইডার ফোন, ডেস্কটপ ওয়েব, পাবলিক ট্র্যাকিং)।
   - বারকোড স্টিকার প্রিন্টিং নীতি (মার্চেন্ট বনাম ব্রাঞ্চ হাব)।
   - Web Audio API সাউন্ড সিন্থেসাইজার কনফিগারেশন।

---

> **সংরক্ষণ নির্দেশিকা:** মূল কুরিয়ার সফটওয়্যার ডেভেলপমেন্টের সময় যেকোনো এপিআই, টেবিল ফিল্ড বা বিজনেস লজিকের প্রয়োজনে এই ডকুমেন্টেশনগুলো হুবহু রেফারেন্স হিসেবে ব্যবহার করা যাবে।
