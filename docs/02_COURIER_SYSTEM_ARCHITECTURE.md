# 🚚 RAJ Courier — Full System Architecture & Tech Blueprint

> **ডকুমেন্টেশন বিবরণ:** এই ফাইলে রাজ কুরিয়ার (RAJ Courier) ম্যানেজমেন্ট সিস্টেমের সম্পূর্ণ আর্কিটেকচার, প্রয়োজনীয় অ্যাপস ও পোর্টালের তালিকা, জিরো-ল্যাগ (Zero-Lag) টেক-স্ট্যাক, ডাটাবেস গাইডলাইন এবং ক্লায়েন্ট প্রেজেন্টেশন স্ট্রাকচার বিস্তারিত লিপিবদ্ধ করা হলো।

## ২. চূড়ান্ত টেক-স্ট্যাক (The Unified TypeScript Stack)

সম্পূর্ণ সিস্টেমটি একটি একক প্রোগ্রামিং ইকোসিস্টেম—**JavaScript / TypeScript**-এ পরিচালিত হবে:

```
[ Frontend: React.js + Tailwind + Shadcn UI ]  ◄──┐
[ Mobile: React Native (Expo) + NativeWind ]   ◄──┼──► [ Backend: Node.js + Fastify (TypeScript) ]
                                                  │         │
                                                  │         ├──► [ Cache & Queue: Redis (ioredis + BullMQ) ]
                                                  │         │
                                                  └─────────┴──► [ Database: PostgreSQL via Prisma ORM ]
```

### স্ট্যাকের বিস্তারিত স্পেসিফিকেশন:

* **কোর ডাটাবেস (Primary DB):** **PostgreSQL**
  * *ভূমিকা:* পার্সেল, মার্চেন্ট, ব্রাঞ্চ, ইউজার এবং টাকা-পয়সার (Double-entry Ledger) মূল এন্টারপ্রাইজ রেকর্ড (ACID + PostGIS)।
* **ডাটাবেস ORM টুল:** **Prisma ORM**
  * *ভূমিকা:* টাইপস্ক্রিপ্টের মাধ্যমে টাইপ-সেফ ডাটাবেস কুয়েরি ও অটোমেটিক মাইগ্রেশন পরিচালনা।
* **ক্যাশ ও কিউ মেমোরি:** **Redis (ioredis)**
  * *ভূমিকা:* ট্র্যাকিং ডাটা মেমোরিতে ক্যাশ করা, রেট-লিমিট এবং ব্যাকগ্রাউন্ড কিউ।
* **ব্যাকএন্ড API ইঞ্জিন:** **Node.js (TypeScript) + Fastify**
  * *ভূমিকা:* হাই-থ্রুপুট RESTful API এবং ওয়েব-সকেট ইভেন্ট হ্যান্ডলার।
* **ব্যাকগ্রাউন্ড জব প্রসেসর:** **BullMQ**
  * *ভূমিকা:* SMS, হোয়াটসঅ্যাপ মেসেজ, পুশ নোটিফিকেশন এবং ভারী এক্সেল ফাইল প্রসেসিং।
* **প্রসেস ম্যানেজার:** **PM2 (Cluster Mode)**
  * *ভূমিকা:* সার্ভারের প্রতিটি CPU কোর ব্যবহার করা এবং জিরো ডাউনটাইম বজায় রাখা।
* **ওয়েব ড্যাশবোর্ড (Admin & Merchant):** **React.js (Vite) + Tailwind CSS + Shadcn UI**
  * *ভূমিকা:* আধুনিক, দ্রুতগতির ও রেসপন্সিভ ডেটা টেবিল, ফিল্টারিং ও চার্ট।
* **রাইডার মোবাইল অ্যাপ:** **React Native (Expo) + NativeWind (Tailwind CSS)**
  * *ভূমিকা:* ফিল্ডে রাইডারদের ব্যবহারের জন্য হালকা ও দ্রুতগতির মোবাইল অ্যাপ।
* **রিভার্স প্রক্সি ও সিকিউরিটি:** **Nginx / Cloudflare**
  * *ভূমিকা:* SSL Termination, HTTP/2 মাল্টিপ্লেক্সিং, ব্রোটলি (Brotli) কম্প্রেশন ও DDoS প্রোটেকশন।

## ৩. উচ্চ লোডেও সিস্টেম ০% ল্যাগ (Zero-Lag) রাখার ইঞ্জিনিয়ারিং পলিসি

1. **Read/Write Splitting (মাস্টার-রেপ্লিকা আর্কিটেকচার):**
   * **Master DB:** শুধু ডাটা এন্ট্রি হবে (রাইডার স্ক্যান, পার্সেল বুকিং, ক্যাশ জমা)।
   * **Read-Replica DB:** সমস্ত রিপোর্ট, অ্যাডমিন ফিল্টারিং এবং পাবলিক ট্র্যাকিংয়ের কুয়েরি হ্যান্ডেল করবে। ফলে ভারী রিপোর্টেও রাইটার ডাটাবেসে ০% লকিং হবে।
2. **Redis Cache-Aside Pattern:**
   * পাবলিক ট্র্যাকিং রিকোয়েস্ট (`/api/v1/track/:code`) ডাটাবেসে না গিয়ে সরাসরি Redis RAM থেকে ২ মিলিসেকেন্ডে রিটার্ন হবে। স্ট্যাটাস বদলালে ক্যাশ অটোমেটিক ইনভ্যালিডেট হবে।
3. **BullMQ দিয়ে অ্যাসিনক্রোনাস কাজ অফলোড:**
   * SMS গেটওয়ে, পুশ নোটিফিকেশন এবং চালান PDF তৈরি কখনোই মেইন API থ্রেডে চলবে না। সেগুলো ব্যাকগ্রাউন্ড ওয়ার্কারে চলবে। ফলে ইউজার ইনস্ট্যান্ট রেসপন্স পাবে।
4. **Composite Indexing ও টেবিল পার্টিশনিং:**
   * কোটি কোটি পার্সেল রেকর্ডের জন্য `(merchant_id, status, created_at)` কম্পোজিট ইনডেক্স এবং `parcel_events` টেবিলকে মাসভিত্তিক (Monthly Range) পার্টিশনিং করা হবে।
5. **Fastify + PM2 ক্লাস্টার মোড:**
   * সার্ভারের ৮টি কোর থাকলে PM2 ৮টি নোড প্রসেস চালু রাখবে। ফলে কনকারেন্ট রিকোয়েস্ট নেওয়ার ক্ষমতা বহু গুণ বৃদ্ধি পাবে।

## ৪. ক্লায়েন্ট প্রেজেন্টেশন ও বোঝানোর গাইড (Client Pitch)

ক্লায়েন্ট বা বিজনেস ওনারদের কাছে এই প্রজেক্টের ভ্যালু তুলে ধরার ৩টি মূল স্তম্ভ:

1. **টাকা চুরি বা গরমিলের কোনো সুযোগ নেই (Zero Cash Leakage):**
   * প্রতিটি টাকার ডিজিটাল ডাবল-এন্ট্রি লেজার থাকবে। রাইডার টাকা তুললে সিস্টেমে এন্ট্রি হবে, ব্রাঞ্চে জমা দিলে ম্যানেজার কনফার্ম করবে। কোথাও ১ টাকার অমিল থাকলে ড্যাশবোর্ডে সাথে সাথে ধরা পড়বে।
2. **১০০% পার্সেল অডিট ট্রেইল (No Lost Parcels):**
   * পার্সেল এক হাত থেকে অন্য হাতে যাওয়ার সময় বারকোড স্ক্যান হবে (মার্চেন্ট ➔ রাইডার ➔ হাব ➔ লাইন-হল ট্রাক ➔ ডেলিভারি হাব ➔ কাস্টমার)। কোনো পার্সেল গায়েব হলে জানা যাবে শেষ স্ক্যান কে করেছিল এবং দায় কার।
3. **আন্তর্জাতিক লজিস্টিকস স্ট্যান্ডার্ড স্পিড (Enterprise Performance):**
   * ঈদের মৌসুম বা পিক-আওয়ারে হাজার হাজার পার্সেল একসাথে বুক ও স্ক্যান হলেও সিস্টেম স্লো বা লোডিং হয়ে বসে থাকবে না; ব্যাংক-লেভেল স্পিডে কাজ করবে।

## ৫. প্রাথমিক ডাটাবেস টেবিলসমূহ (Database ERD Outline)

* `users` — অ্যাডমিন, হাব ইনচার্জ, রাইডার, মার্চেন্ট ক্রেডেনশিয়াল ও পারমিশন।
* `hubs` — সারা দেশের জেলা ও লোকাল হাবের তালিকা ও লোকেশন।
* `merchants` — দোকানের নাম, ব্যাংক/বিকাশ একাউন্ট, রেট ও কমিশন সেটিংস।
* `parcels` — ট্র্যাকিং কোড, মার্চেন্ট আইডি, কাস্টমার তথ্য, ওজন, সিওডি (COD) এমাউন্ট, বর্তমান স্ট্যাটাস।
* `parcel_events` — পার্সেলের প্রতিটি ধাপের টাইমস্ট্যাম্প, লোকেশন ও অডিট লগ।
* `challans` — এক হাব থেকে অন্য হাবে পাঠানোর জন্য হাইওয়ে লোডিং চালান।
* `transactions` — সংগৃহীত ক্যাশ, ব্রাঞ্চ ভল্ট এন্ট্রি এবং মার্চেন্ট উইথড্রয়াল লেজার।
